# 📦 Violoader v7.2.0 — Мой интересный нейрослопчик


> **ВНИМАНИЕ:** Мой личный вайб-код проект, сделанный чисто от скуки в диком танце между паникой в Discord, отваливающимся интернетом в Radmin VPN и нейросетью DeepSeek, писавшей код под моим QA-руководством со скоростью пулемета. 

Программа создана за сутки в режиме экстремального ИИ-дирижирования, чтобы раз и навсегда избавить мою пати от технического тупняка перед каткой. А еще тут есть тема Windows 96 назло другу, который назвал первую версию интерфейса старым!

---

## 💡 Главная идея проекта (Для кого это?)

Violoader создан для двух типов игроков, без которых не обходится ни одно выживание:

1. **Для тех, у кого лапки 🐾 (Не умеют ставить моды):**
   В каждой компании есть друг, который при попытке поставить сборку обязательно закинет `.jar` файл не туда, перепутает версию Fabric с Forge, забудет скачать базовое API и в итоге сломает себе игру. Violoader решает это: друг просто вводит PIN-код, нажимает одну кнопку, и программа **сама** раскладывает все моды, конфиги, шейдеры и текстуры по нужным папкам.
2. **Для тех, у кого интернет из картошки 🥔 (Слабый коннект):**
   Если у хоста сборка весит 600 МБ, а у друга скорость скачивания как в 2007 году, то при малейшем обрыве связи качать ZIP-архив заново — это пытка. Violoader works через **SHA-256 Delta Sync**. Он сравнивает файлы хоста и гостя и перекидывает **только то, чего реально не хватает**. А если сеть моргнет прямо посреди передачи — умная докачка подхватит файлы `.vpart` с точностью до байта с места обрыва!

## 📊 Как это работает на рутине

| Проблема обычных сборок | Что чувствует пати перед игрой | Решение в v7.2.0 Slop Edition |
| :--- | :--- | :--- |
| **Сложная установка** | «Куда кидать конфиги? Почему у меня крашится? Где папка %appdata%?» | **🎪 Мультиплеер лобби (Пати-комнаты)**. Один PIN-код, и всё ставится автоматически. |
| **Обрыв загрузки** | «Интернет моргнул на 99%, и теперь всё качать с нуля?!» | **Умная докачка и дозапись сокетов**. Файлы продолжают литься с места обрыва. |
| **Зависание Java в фоне** | «Пишет 'файл заблокирован', хотя я всё закрыл! Помогите!» | Кнопка **Force Kill Processes** принудительно гасит `javaw.exe` и лаунчеры в 1 клик. |
| **Картинка отличается** | «Мы зашли, у хоста красивые облака и текстуры, а у меня обычная ванилла». | Авто-синхронизация соседних папок `shaderpacks` и `resourcepacks`. |

## 🎯 Ключевые фичи

* **🎪 Режим Пати-Лобби:** Хост открывает комнату, генерируется 6-значный PIN. Друзья вводят его и автоматически залетают в лобби, скачивая сборку в параллельных потоках без ручной возни с IP.
* **👦 Аватарки со скинами (Mojang API):** В блоке текущей Пати отображаются пиксельные головы участников. Программа сама стучится на сервера скинов и подтягивает аватарку по никнейму. Карточка хоста всегда первая!
* **⚡ Неубиваемый Web-UI на нативном JS:** Навигация сайдбара переписана на чистый, дубовый `onclick`, который идеально работает как в сырой пэушке (`.py`), так и внутри скомпилированного `.exe`.
* **🔥 Огненный визуал (Canvas-движки):** Вруби тему *Chronos* и наблюдай за неоновым потоком времени, который эффектно глитчит при сетевых ошибках (`triggerChronosGlitch`).
* **🛑 Мгновенный убийца лаунчеров:** Используя `psutil`, программа мгновенно освобождает папку `mods`, закрывая TLauncher, Prism, Legacy или зависшую в фоне Java.
* **🧠 Анализатор логов игры:** Нажал «Краши» — Viолоader залез в `latest.log`, нашел причину (`OutOfMemoryError` или конфликтующий Fabric/Forge) и выдал человеческий совет по лечению.
* **🔌 Полный No-Chat:** Из программы полностью вырезан чат. Это разгрузило сетевые порты, убрало нагрузку на процессор и убрало 90% фризов. Все созвоны и так идут в Discord!

## 🚀 Инструкция по запуску

### 🎮 Для обычных игроков (В один клик):
1. Перейди во вкладку **Releases** справа.
2. Скачай готовый файл `violoader.exe`.
3. Запусти, введи свой никнейм — и ты в игре!

### 💻 Для разработчиков (Из исходников):
Программа принципиально написана в **один файл** и не имеет жестких pip-зависимостей (всё опциональное подключено через graceful fallback).

```bash
# Установка базового графического движка
pip install pywebview pillow

# Опционально для системного трея, уведомлений ОС и работы с процессами
pip install pystray plyer qrcode[pil] psutil

# Запуск скрипта
python violoader.py
```

## 🛠️ Как собрать свой собственный `.exe`

Если ты внес изменения в HTML-интерфейс или бэкенд и хочешь упаковать программу для своих друзей со встроенной иконкой-дискетой, выполни команду в PowerShell:

```powershell
pyinstaller --onefile --windowed --name violoader --icon=icon.ico --hidden-import=clr --hidden-import=webview.platforms.edgechromium --clean violoader.py
```
*Флаг `--clean` очистит старый бинарный кэш, а `--windowed` уберет черное окно консоли Windows при старте лаунчера.*
